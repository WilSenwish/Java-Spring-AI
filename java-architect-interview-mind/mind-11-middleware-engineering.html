主题卡详情

① 流程与规则 · 章节题

C11.01 Activiti BPMN 2.0 执行原理
BPMN 元素(事件/网关/任务) → 流程引擎解析/部署 → 流程实例+令牌推进；控制任务分配、网关分支与事务边界。是"工作流引擎选型 + 建模"的根基。
章节工作流BPMN
C11.02 流程节点批量配置化
流程模板化、节点参数外部化配置（数据库/配置中心）、审批人规则动态解析；避免硬编码，支持灰度调整。是流程引擎的可维护性工程。
章节配置化
C11.03 规则引擎执行原理与选型
QLExpress(快) vs Drools(RETE 推理)；规则的正则化、冲突消解、命中率与热更新。适用复杂多变业务规则，把"规则"从代码中剥离。
章节规则引擎
C11.12 分布式任务调度设计与选型
Quartz(单机)/XXL-Job(分片/调度中心)/Elastic-Job(自管理分片)；触发、分片、失败重试、故障转移。选型看规模与运维习惯。
章节任务调度
C11.16 Nacos 与 Apollo 配置中心选型
Nacos(长轮询+一致性)/Apollo(多环境+灰度+权限)；从一致性、回滚、灰度与权限对比。配置中心是动态治理的底座。
章节配置中心
C11.21 分布式定时任务框架对比
Quartz/XXL-Job/Elastic-Job 适用场景：触发方式、分片模式、控制台与故障处理差异。是任务调度选型的细化。
章节调度框架
C11.22 时间轮与延时任务实现
HashedWheelTimer 时间轮精度/内存权衡、DelayQueue、Redis(ZSET) 延时；从延迟精度与集群化取舍。是"延时任务"的实现三选。
章节时间轮
C11.23 分布式定时任务不重不漏
幂等、动态分片、多机房/多副本执行防重复、故障转移与补偿；leader 选举+本地表唯一约束兜底。是"只跑一次"的成功要件。
章节不重不漏

② 安全与观察 · 章节题

C11.04 OAuth 2.1 三种授权模式与安全
授权码(PKCE)/设备码/客户端凭证；废弃隐式与密码模式；token 轮换、状态参数与 PKCE 防拦截。是现代认证接入的安全规范（呼应 Security 手册/E09.03）。
章节OAuth
C11.05 JWT 数据结构与安全实践
Header.Payload.Signature、签名算法(HS/RS)、过期/issuer/aud、防重放(jti)；存 Redis 做撤销与登出。是"无状态令牌"的安全边界。
章节JWT
C11.07 APM 全链路监控架构
探针采集(调用链/指标/日志)→后端聚合→展示告警；Trace/Span 模型、采样与存储治理。是"监控体系怎么建"的架构题。
章节APM
C11.08 TraceId 多线程跨服务透传
MDC + ThreadLocal、异步/线程池透传(TransmittableThreadLocal)、跨服务 header 传递；防断链。是分布式追踪的工程细节。
章节TraceId
C11.09 可观测三支柱与 OpenTelemetry
Metrics/Traces/Logs 统一上下文关联、SDK/收集器/后端；标准与厂商无关。呼应 ch10 可观测、E11.03。
章节OTel
C11.10 混沌工程验证韧性
假设→最小爆炸半径→受控注入故障(网络/CPU/依赖)→观测→改进；故障演练平台化。S08.03 是其场景落地。
章节混沌工程
C11.19 eBPF 无侵入可观测
内核级采集、zero-instrumentation、与 OTel/Agent 边界；适合追网络/内核视角的观测盲区。
章节eBPF
C11.20 成本优化 / FinOps
云账单治理：预算/峰谷调度、资源弹性、FinOps 责任共担与文化。是"降本增效"的工程化管理。
章节FinOps

③ 搜索消息与工程 · 章节题 + 八股 + 场景

C11.13 Elasticsearch 倒排/分片/集群
倒排索引(分词/postings/BM25)、分片路由/副本同步、段合并与写入调优；集群高可用与容量规划。S11.01 是其集群实战。
章节Elasticsearch
C11.11 Kafka 高可用与 Exactly-Once
集群多副本身份、ISR 与 leader 切换、事务幂等 Exactly-Once；与 ch09 链路呼应。
章节Kafka
C11.14 分布式任务调度与搜索整合
任务中心设计（分片/路由/产物）+ 与搜索等异步链路协作，保证"不重不漏 + 幂等消费"。
章节任务中心
C11.15 gRPC + Protobuf 高性能通信
HTTP/2 多路复用、ProtoBuf 二进制编码、流式调用与拦截器；服务定义/代码生成。比 HTTP/1.1+JSON 更省包体更低延迟。
章节gRPC
C11.17 Flyway vs Liquibase 迁移实践
版本化 DDL 变更、回滚与团队协同；Flyway(SQL 直观)/Liquibase(XML 抽象)；与 CI 集成、环境差异管理。
章节迁移
C11.18 Kafka 与 RocketMQ 选型
吞吐/事务消息/延迟队列(顺势)/顺序消息对比；Kafka 大数据吞吐、RocketMQ 业务消息便利。选型看业务形态。
章节选型
