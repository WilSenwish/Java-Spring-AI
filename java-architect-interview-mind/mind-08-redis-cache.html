① 数据与持久化 · 章节题 + 八股

C08.01 Redis 的 5+4 种数据结构与应用场景
5 基础：String/Hash/List/Set/ZSet；4 扩展：BitMap/HyperLogLog/GEO/Stream。选型映射场景（计数、漏斗、排行榜、布隆去重、附近的人、消息队列）。答"场景→结构"反推是加分项。
章节数据结构
C08.02 RDB 与 AOF 持久化的权衡
RDB 快照体积小、恢复快、可能丢最后一次快照；AOF 记录每次写、可加大 fsync 保障、重写控制体积；混合模式（AOF 头+RDB）+ 合适 fsync 策略是生产默认。答"丢失窗口 vs 性能"。
章节持久化
C08.09 过期策略与内存淘汰机制
惰性删除 + 定期抽样删除；内存满时按 maxmemory-policy：noeviction/allkeys-lru/volatile-lru/lfu/random。配合过期键避免"过期键堆积"，LRU/LFU 选型与业务热点匹配。
章节淘汰过期
C08.11 Redis Stream 作为消息队列的设计
持久化消息、消费组/ACK/pending list；对比 List 简陋消息队列。适用"需可靠+多消费者组"的场景，配合 XADD/XREADGROUP/XACK 理解投递语义，避免重复/丢失。
章节Stream消息队列

② 一致性与锁 · 章节题 + 八股 + 场景

C08.03 缓存穿透/击穿/雪崩的区别与解决
穿透=查不存在（布隆/空值缓存）；击穿=热点 key 过期（互斥锁/逻辑过期）；雪崩=大量 key 同时失效或 Redis 宕（随机过期/多级/高可用）。三问常联考，要能区分并给方案。
章节穿透击穿雪崩
C08.04 缓存与数据库一致性如何保证
Cache Aside 更新改"先更新库再删缓存"；延迟双删、Canal 订阅 binlog 异步删；最终一致 + 失败重试。弱一致场景接受短暂不一致，强一致场景慎用缓存。是 2026 高频题与 S02.05 互通。
章节一致性
C08.05 Redisson 分布式锁如何可重入与看门狗
基于 Lua 保证加锁原子性，hash 结构计数实现可重入；看门狗后台续期默认 30s 防业务未结束锁被释放；解锁 Lua 判断持有者。讨论与 RedLock 争议、以及"锁粒度+自动续期+并发安全"。
章节分布式锁看门狗
C08.06 多级缓存架构如何设计
L1 本地缓存（Caffeine）+L2 Redis+L3 DB，配一致性推送/失效广播与回源保护；针对热点读设计"就近越快"。评估一致性、命中率与内存治理。
章节多级缓存
C08.10 高并发场景常见问题与优化
大 key/热 key 打散与拆分、Pipeline 批量、连接池复用、读写分离、避免慢命令（大 Range、Keys）、热点读写放大。答"识别问题→针对性手段"。
章节高并发优化

③ 集群与防护 · 章节题 + 八股

C08.07 Redis Cluster 的工作原理
16384 槽位映射到节点、client 重定向(moved/ask)、主从复制 + 节点间 gossip；无中心、故障转移。对比哨兵：Cluster 面向海量数据分片，Sentinel 面向主从高可用。
章节Cluster
C08.08 布隆过滤器原理与缓存穿透防护
m bit + k hash 函数，判断"一定不存在"高的假阳率；空间最优、不可删除。用于拦截不存在 key 的穿透请求。关联 E12.03 跳表/布隆速记。
章节布隆过滤器
