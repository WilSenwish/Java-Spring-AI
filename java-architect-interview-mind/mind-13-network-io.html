主题卡详情

① 协议栈 · 章节题 + 八股 + 场景

C13.01 OSI 七层与 TCP/IP 四层映射
七层与四层对应关系、各层核心协议与数据封装（帧/段/包）；答"从应用层到链路层的逐层拆解"体现纵深理解。
章节分层模型
C13.02 TCP 三次握手/四次挥手状态机
握手建立连接、挥手释放连接、TIME_WAIT 与 CLOSE_WAIT 根因与处理；答状态机 + 实际排查（大量 TIME_WAIT 的调优）。
章节TCP
C13.03 HTTP/1.1 vs 2 vs 3
1.1 队头阻塞/连接复用；2 多路复用+二进制帧但 TCP 队头；3 基于 QUIC/UDP 彻底去队头。选型看弱网与连接数诉求。S10.03 协议升级印证。
章节HTTP
C13.04 HTTPS/TLS 1.2 与 1.3 握手
证书链验证、密钥交换（RSA vs ECDHE）、前向安全、1.3 简化握手(1-RTT/0-RTT)；把"为什么安全"讲清。E09.02 八股同题。
章节TLS

② NIO 与 Netty · 章节题 + 八股 + 场景

C13.05 Java NIO：Selector/Channel/Buffer
Selector 多路复用 IO 事件、Channel 双向通道、Buffer 读写翻转（flip/clear）；一个线程管理多连接是高并发接入的关键。
章节NIO
C13.06 Netty 线程模型与 ChannelPipeline
Boss/Worker EventLoop 线程模型、ChannelPipeline+Handler 流水线、异步驱动；Reactor 多线程变体。是 Java 网络框架的地基。
章节Netty
C13.07 ByteBuf 池化、引用计数与泄漏排查
池化减少分配、引用计数(release)、泄漏检测(LeakDetector)；答"池化生命周期 + 泄漏元凶与排查手段"。
章节ByteBuf
C13.08 零拷贝：sendfile/mmap/DMA
减少用户态/内核态拷贝：sendfile 内核直传、mmap 映射、DMA 硬件搬移；Java 中 FileChannel.transferTo 落地。是高性能 IO 的核心抓手。
章节零拷贝

③ 应用与内核 · 章节题 + 场景

C13.09 WebSocket 握手、心跳与断线重连
HTTP Upgrade 握手、Frame 传输、心跳保活与断线重连策略、粘包处理。S10.04 行情推送印证。
章节WebSocket
C13.10 DNS 解析与智能调度
递归/迭代解析、缓存 TTL、HTTPDNS 防劫持、CDN 边缘调度；理解"就近访问"与"故障切换"。
章节DNSCDN
C13.11 io_uring 异步 IO 与 Loom
io_uring 内核异步接口、与 JDK Project Loom 虚拟线程的关系；理解"异步化如何支撑 Java 高性能网络"。
章节io_uring
C13.12 系统调用与内核交互
用户态/内核态切换、read/write/epoll/sendfile 系统调用如何支撑 Java 网络；答"从应用到内核的 IO 全路径"。
章节系统调用
C13.13 IO 模型全景与跨平台选型
UNP 五模型补全 signal-driven IO；Windows IOCP/Proactor 完成驱动；全接口横向对比（select/poll/epoll/kqueue/io_uring/IOCP）；Reactor vs Proactor。与 C13.05/11/12 拼成 IO 模型全景。
章节IO 模型
