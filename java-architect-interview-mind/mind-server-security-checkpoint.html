① 认证与会话 · 手册章节 + 八股 + 场景

第 1 章 认证与授权安全
身份认证基础与认证因素、口令策略与口令存储（加盐+慢哈希）、多因素认证与无密码认证、授权模型（RBAC/ABAC）、OAuth2/OIDC 协议安全、JWT 与令牌安全。
手册认证授权
第 2 章 会话管理
会话生命周期、会话令牌生成与传输（HttpOnly/Secure）、会话固定/劫持与超时、CSRF 防护（SameSite/Token）、分布式会话与 Redis 会话安全。
手册会话

② 输入输出与密码学 · 手册章节 + 八股 + 场景

第 3 章 输入输出安全
输入验证与数据净化、注入防御（SQL/命令/LDAP）、XSS 防御（编码/CSP）、SSRF 防御（白名单/内网隔离）、文件上传与下载安全、反序列化安全（白名单/过滤）、输出编码与响应头安全。
手册注入XSS/SSRF
第 4 章 密码学
密码学设计原则与威胁模型、对称加密（AES 模式）、非对称加密与密钥协商、哈希函数、MAC 与数字签名、口令哈希与 KDF（bcrypt/argon2）、随机数与熵源、密钥管理、证书与 TLS、密码算法雷区总清单。
手册密码学
第 5 章 错误处理与日志
安全错误处理与异常管理（不泄露堆栈）、安全日志实践（关键事件记录/脱敏）、敏感信息泄露防护（避免日志打明文密钥与个人信息）。
手册日志

API 认证与授权、限流/配额与防滥用、数据保护与响应最小化、版本管理与生命周期、第三方集成与供应链安全、GraphQL 安全。
