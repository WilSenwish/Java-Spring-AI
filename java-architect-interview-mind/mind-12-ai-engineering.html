主题卡详情

① 检索与生成 RAG · 章节题 + 八股 + 场景

C12.01 Spring AI 核心架构与整合模式
统一 ChatClient/EmbeddingModel 抽象、模型 API 封装、VectorStore 与工具调用；类比"JDBC 之于数据库"做模型 STOST 层。是 Java 侧构建 LLM 应用的骨架。
章节Spring AI
C12.02 RAG 完整流程与各环节优化
索引(分块→Embedding→入库) + 检索(向量/关键词/混合+重排) + 生成(Grounding/引用) 三阶段；每阶段一个提升点。是 2026 最高频 AI 题。
章节RAG
C12.03 向量 Embedding 与相似度检索数学原理
文本→高维向量、余弦/内积距离、ANN 索引（HNSW/IVF）召回近似最近邻；维度爆炸与归一化。是"为何语义检索能工作"的底层。
章节Embedding
C12.04 Chunking 分块策略对 RAG 效果影响
按语义/标题/固定长度分块、块重叠与上下文窗口、检索单元 vs 生成单元分层；不同文档类型策略不同。是"调 RAG 的第一步"。
章节分块
C12.22 十亿级向量库选型与性能调优
Milvus/Qdrant/ES+插件对比：存算分离、索引(HNSW/IVF/DiskANN)参数、内存/召回/构建成本；关联 ch14 向量库章。
章节向量库
C12.16 RAG 召回率低与幻觉生产级治理
召回的检索质量（混合/重排/块优化）+ Grounding(引用溯源) + 低阈值拒答；幻觉由"检索命中"+"输出约束"双重治理。
章节幻觉

② 智能体与编排 · 章节题 + 场景

C12.06 Spring AI Function Calling 让 LLM 调用工具
声明 tools→LLM 返回 tool_call→运行时执行→结果回填再生成；是"LLM 连接系统"的关键能力，配错误处理与权限控制。
章节Function Calling
C12.07 Agent 框架与 MCP 协议
ReAct 推理-行动循环、规划/记忆/工具三大件；MCP 标准化工具/资源/上下文接入，让 Agent 生态互通。
章节AgentMCP
C12.05 Prompt 工程核心技巧与模板
角色/任务/上下文/输出约束结构化、few-shot、思维链；含变量与安全边界。是"拥抱效果"的低成本杠杆。
章节Prompt
C12.11~15 多框架编排与 MultiAgent
Spring AI Alibaba Graph、AgentScope-Java(ReAct)、LangChain4j AiServices、LangGraph4j StateGraph；从"单 Agent"到"图编排 + MultiAgent 协作"是 Java AI 工程主线。
章节多Agent败境编排

③ 治理与防护 · 章节题 + 场景

C12.17 LLM 流式响应与 SSE 端点
stream() 流式返回、SSE 增量输出、前段打字机效果；兼顾断连恢复与背压（S12.07）。是"LLM 应用的用户体验底座"。
章节流式SSE
C12.18 LLM 限流/熔断/降级/超时治理
模型服务抖动不拖垮主链路：超时、重试退避、断路器、降级兜底、令牌桶限流。是"LLM 网关防雪崩"的专项。
章节限流熔断
C12.19~20 AI 安全纵深与多模型容灾
Prompt 注入/越狱/数据泄露防护、Guardrails 护栏；多模型路由与故障转移，单供应商故障容灾 + 成本最优。
章节AI安全多模型
C12.23~26 Agent 治理与成本防治
工具调用失败/死循环/超预算治理、结构化输出解析兜底、流式断连恢复、Token 语义缓存/分级路由/上下文裁剪。是"AI 上生产的四大坑"治理集。
章节Token成本Agent治理
C12.29~31 评测/灰度/合规
LLM 评测集与 CI 质量卡门、模型版本灰度 A/B、长记忆/会话存储与隐私合规（留存/脱敏/审计）。是"AI 平台化"的工程闭环。
章节合规评测
