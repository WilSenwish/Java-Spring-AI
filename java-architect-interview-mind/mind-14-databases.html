① 文档与向量 · 章节题

C14.01 MongoDB 文档模型/分片/事务
BSON 文档模型、分片键与 chunk 路由、副本集高可用、多文档事务(mongo 4.x 起)；适用灵活 schema 与高写场景。选型看一致性/事务需求。
章节MongoDB
C14.02 MongoDB 做向量检索
Atlas Vector Search ANN 原理、混合查询(全文+向量)优化；与专业向量库的边界。呼应 ch12 向量检索。
章节向量检索
C14.03 Milvus 十亿级向量
存算分离架构、IVF/HNSW/DiskANN 索引权衡、多副本与高可用；"成本 vs 召回"的工程取舍。与 ch12/C12.22/E10.03 联动。
章节Milvus
C14.04 Qdrant 过滤检索与 Payload 索引
Rust 实现高性能、payload 过滤与索引、filtering 查询优化；对比 Milvus 的多租户与过滤能力差异。
章节Qdrant
C14.13 慢 SQL 值班动作

慢 SQL 值班先止血再优化：定位语句 → 评估锁与复制延迟 → 限流/杀会话 → 再谈索引。

排查：见章节卡「落地排查」层；回滚：失败模式：未止血先改代码；错误索引锁表；忽略复制延迟。回滚点：撤销错误索引变更或恢复旧 SQL。…

② 分布式与列存 · 章节题 + 场景

C14.05 TiDB HTAP：OLTP+OLAP
Raft 共识保证强一致、Percolator 分布式事务、TiFlash 行列双引擎支撑 HTAP；解决"一份数据同时跑交易与分析"。
章节TiDBHTAP
C14.06 ClickHouse 列存为何适合 OLAP
列式存储压缩、MergeTree 家族引擎、物化视图加速、向量化执行；适用大吞吐聚合分析。S11.04 是其落地。
章节ClickHouse
C14.08 分布式 SQL/NewSQL 选型边界
CockroachDB/YugabyteDB/OceanBase/TiDB 对比；从一致性、扩展、生态与 MySQL 兼容性界定选型边界。
章节NewSQL
C14.10 PostgreSQL 体系化选型
MVCC/VACUUM、扩展生态(PostGIS/pgvector/Timescale)、与 MySQL 选型边界；互链 C07.07、C14.08/C14.09。
章节PostgreSQL
C14.11 Doris/StarRocks vs ClickHouse
MPP 实时数仓、高并发明细与 JOIN；与 C14.06 ClickHouse 宽表扫描主场对照。
章节Doris
C14.12 CDC 端到端管道
Debezium→Kafka→湖仓/ES；位点、保序、幂等、对账；与 C09.16 Outbox 分工（领域事件 vs 数据面）。
章节CDC

③ 图与时序 · 章节题 + 场景

C14.07 图数据库建模与查询
节点/关系建模、Cypher 模式匹配、Neo4j 适用场景；答"社交/风控/推荐等关系密集场景才值得上图库"。SAAS风控 S07.02 可呼应。
章节图数据库
C14.09 时序数据库适配场景
InfluxDB/TimescaleDB 适用监控指标/物联网时序；downsample、保留策略与查询模式；对比关系库存时序的优劣。
章节时序库

场景OLAP
