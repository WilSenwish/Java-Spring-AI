① 自动配置内核 · 章节题 + 原理

C06.01 Spring Boot 自动配置的 SPI 机制如何工作
@EnableAutoConfiguration→读取 META-INF/spring.factories 或 AutoConfiguration.imports→按 @Conditional 条件装配→生成自动配置 Bean。核心是"约定优于配置 + 条件化装配"，是 Spring Boot 的工厂 SPI。
章节自动配置SPI
C06.02 Spring Boot 3.x AOT 与 GraalVM Native Image
AOT 编译期生成运行时元数据（字节码增强 + 提前初始化）；GraalVM 封闭世界假设需 reflection/proxy/resource 配置清单。配合 Spring 6 的 @Autowired 变更与 nativeHints 显式声明，追求毫秒级冷启动与低内存。
章节AOTGraalVM
C06.03 如何设计一个自定义 Spring Boot Starter
autoconfigure 模块定义 AutoConfiguration + @ConditionalOnXxx + 配置属性类（@ConfigurationProperties 开启 metadata）；starter 模块只做依赖与 META-INF 元数据。是"自动配置 SPI"的业务复用样板。
章节Starter
C06.08 Spring Boot 配置加载与优先级
加载顺序：命令行→JVM 系统属性→application-{profile}→application→外部 config data 等，same-key 后者不一定覆盖，遵循"来源与顺序双坐标系"。答要点：DEV/PROD 多环境分层 + 敏感配置不入库。
章节配置优先级

② 安全与校验 · 章节题

C06.04 Spring Security 过滤器链与认证授权流程
请求进入 SecurityFilterChain→AuthenticationFilter 认证→AuthenticationManager→Provider→UserDetailsService→SecurityContext 持有→AuthorizationFilter 授权（方法/URL 级）。理解"过滤器链 + 认证对象 + 授权决策"三段式。
章节Security过滤器链
C06.06 Spring Session 实现分布式 Session
用 Redis/Database SessionRepository 顶替本地 HttpSession，后端集群共享会话；支持失效、监听与来源切换。适合非 JWT 的传统会话诉求，注意序列化与失效策略。
章节Session
C06.10 Spring Validation 数据校验机制
JSR-303 Bean Validation（@NotNull/@Size/@Email）由 Hibernate Validator 执行；结合 @Valid/@Validated 触发分组校验与自定义 validator。强调：方法级校验需 @Validated，Controller 自动触发。
章节Validation
C06.11 Spring Security 6 安全架构与 OAuth2 实践
Security 6 用 Lambda DSL、默认 CSRF 开启、AuthorizationManager 决策；OAuth2 落地走"授权码 + PKCE + JWT access + Refresh 轮换"。与 security 手册、E09.03 联动，是现代 API 安全的标配范式。
章节Security6OAuth2

③ 生产与云原生 · 章节题

C06.05 Spring Boot 启动流程与事件机制
run()→EnvironmentPrepared/ContextPrepared/Started 等事件驱动阶段，是启动生命周期观察点。搭配 Actuator 与链路追踪可做启动耗时治理。
章节启动流程事件
C06.07 Spring Boot Actuator 监控端点与自定义
health/metrics/info/prometheus 等端点；通过暴露策略、自定义 HealthIndicator、Micrometer 指标接入监控体系（关联 Prometheus/Grafana）。生产需鉴权与最小暴露。
章节Actuator
C06.09 Spring Boot 全局异常处理设计
@RestControllerAdvice + @ExceptionHandler 统一兜底，制定错误码与响应结构（ApiResponse）；区分业务异常/系统异常/Auth 异常，避免堆栈外泄。是规范整洁响应体的工程底座。
章节异常处理
C06.12 优雅停机与 K8s 滚动发布协同
spring.lifecycle.timeout 与 shutdown 模式，等待在途请求完成后退出；对接 K8s：readinessProbe 摘流→PreStop 优雅下线→livenessProbe 探活。是"发布不惊动流量"的关键协同。
章节优雅停机K8s
C06.13 云原生 Java：Quarkus/Micronaut vs Spring Boot
Quarkus(构建时元数据+GraalVM 友好)、Micronaut(编译时 DI) 主打低内存快启动；Spring Boot 生态成熟但内存/启动偏重（AOT 可补齐）。选型看开发效率、生态与运行时预算。
章节云原生选型

① 原理并入党：自动配置速记 · 核心原理

原理 E04.02 Spring Boot 自动配置装配
@EnableAutoConfiguration + spring.factories/AutoConfiguration.imports + @Conditional。与 C06.01 同题双入口；进阶答：自动配置装配顺序、ConditionalOnXxx 的求值时机。
原理自动配置
原理 E01.04 GraalVM Native Image 兼容性治理
封闭世界假设下反射/动态代理/资源需显式命册；Spring Boot 3 AOT 自动收集 metadata。与 C06.02 完全同题。
原理GraalVM
