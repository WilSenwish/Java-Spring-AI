主题卡详情

① 服务治理 · 章节题 + 八股 + 场景

C10.01 注册发现与配置中心选型
服务注册/心跳/发现：Eureka(AP)/Nacos(AP~CP)/Consul(CP)；配置中心 Nacos/Apollo 动态刷新。从一致性、健康检查与生态权衡。
章节注册中心配置中心
C10.02 API 网关的核心职责
统一入口：路由、鉴权、限流、熔断、聚合、协议转换、灰度；横向关注与性能开销。Gateway 生产级要素（GlobalFilter 顺序、线程池、连接池）。
章节网关
C10.03 高并发限流熔断降级策略
限流(令牌桶/漏桶/滑窗/热点) + 熔断(错误率阈值/半开) + 降级(兜底值/异步)；Sentinel/Resilience4j 实现。配"降级保底"决策，避免级联雪崩。
章节限流熔断
C10.05 Service Mesh(Istio) 解耦治理
Sidecar 注入透明代理流量，控制面下发路由/熔断/观测策略；应用无侵入。权衡：性能开销、复杂度 vs 治理统一。S04.05 是其场景落地。
章节Service Mesh
C10.06 单体到微服务演进路径
从单体拆分优先按业务域垂直切分（DDD 限界上下文）、渐进式拆分与数据治理、避免为拆而拆。S04.01 是其实战样板。
章节演进拆分
C10.09 灰度发布与蓝绿部署设计
灰度：按流量/用户/特征分批上线、指标观察与回滚；蓝绿：两套环境切换、快速回切。侧重安全发布与可观测配合（呼应 S04.04 流量染色）。
章节灰度发布
C10.13 微服务安全与零信任
东西向流量 mTLS、认证鉴权(ACL)、最小权限、持续验证与微分段；配套密钥管理与审计。安全手册联动。
章节零信任

② 云原生运行时 · 章节题 + 八股 + 场景

C10.04 容器化与 K8s 部署 Java 应用
Docker 分层镜像/多阶段构建、K8s Pod/Deloyment/Service/Ingress、资源配置与弹性伸缩；JVM 容器内存感知与会话/探针配置。S06.04 是其场景化。
章节K8s
C10.10 Serverless 的适用场景与挑战
冷启动、弹性、按量计费适合突发/低频负载；局限：长连接/状态、供应商锁定、调试难度。选型看流量性质与团队运维能力。
章节Serverless
C10.12 云原生 CI/CD 与 GitOps 实践
流水线构建→镜像→部署；GitOps 以 Git 为唯一事实源、ArgoCD 自动协同；配合镜像版本化、环境隔离与审批。增强可审计与回滚能力。
章节GitOps

③ 架构与治理 · 章节题 + 八股 + 场景

C10.07 高可用架构设计原则
冗余/故障隔离/优雅降级/容量规划/演练；配合多活与容灾落地 SLO。呼应方法论"高可用"主题，为架构师答题定调。
章节高可用
C10.11 微服务间数据一致性保证
本地消息表/事务消息最终一致、SAGA 补偿、分布式事务选型；强调"跨服务不 share 数据库 + 事件驱动最终一致"。呼应 ch09 事务章。
章节数据一致性
C10.14 多租户架构设计
共享 Schema/独立 Schema/独立实例三级隔离；租户路由、配额与数据安全；SaaS 场景组合。S07.05 跨境电商多租户是实战。
章节多租户
C10.15 可观测性三大支柱
Metrics/Traces/Logs 关联统一采集、告警与定位；是微服务排障底座的工程化（呼应 C11.09、E11.03）。
章节可观测
C10.16 CQRS 与 Event Sourcing
读写分离模型、事件溯源作为事实源、投影重建读模型；适用复杂业务审计与高写读分离，成本是最终一致与重建。体现"架构选型思维"。
章节CQRSEvent Sourcing
C10.17 SLO/SLI 错误预算驱动发布
SLI 定义指标→SLO 目标→Error Budget 控制发布节奏与容量投入；让可观测服务于业务决策。与 S08.05 SLA 容量规划互通。
章节SLO错误预算
