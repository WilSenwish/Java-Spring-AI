1. 六家 CPU 厂商、三条技术路线：一张决策级对比表

申威SW64 / sw_64源于 Alpha 架构深度改进，发展出自主 SW64高最高：生态最窄超算、特种领域、高性能计算；近年尝试向民用拓展

1.1 三条技术路线的本质权衡（六家厂商归入其中）

                     生态兼容 / 迁移成本  ←────────────→  长期自主可控
 x86 授权  (海光/兆芯)   ●────────────────────────────○     起点高、天花板受授权约束
 ARM 授权  (鲲鹏/飞腾)   ────────●────────────────○         开源生态红利、架构版本风险
 自主指令集(龙芯/申威)   ────────────────●────────●       可控性最强、生态需从零积累
  • x86 路线：把迁移成本降到最低，代价是底层指令集专利与技术演进方向依赖外部授权方；适合存量系统庞大、闭源组件无法重编译的甲方。
  • ARM 路线：享受 aarch64 的开源软件红利，同时保持较高能效比；代价是指令集版本演进依赖授权链。业界普遍判断国内厂商未获得 ARMv9 永久授权〔C，多家行业分析一致转述，但非官方确认，不宜作为确定事实引用〕。
  • 自主指令集路线：长期演进不受外部指令集约束，但需要自建整个软件栈；龙芯近年通过 LoongArch 把 OS、编译器、主流开源软件带起来，申威更集中于超算与特定领域。

1.2 选型时真正要问的五个问题

  1. 业务依赖的闭源软件、监控 Agent、数据库驱动、硬件加密组件是否有对应架构版本？这是 x86→非 x86 迁移中最常见的硬阻塞。
  2. 是否存在 C/C++ 本地编译模块、JNI 库、.so 依赖？这些必须按目标架构重新编译。
  3. 目标 OS 是否有对应内核版本与驱动支持（尤其 GPU、网卡、RAID/HBA、UKey、打印机、扫码枪）？
  4. 供应保障：该型号的量产成熟度、备货周期、迭代路线与售后能力如何？
  5. 合规要求：本项目是否要求特定安全可靠测评等级，以及该等级对应的具体产品型号与公告版本？

工程提示：决策前先执行 uname -m 与目标环境验证，确认架构标识。有案例记录团队在未真正切换架构的环境上做了一周「迁移」〔C，技术博客〕。看似基础，但在多架构混合云环境中确实高发。

1.3 常见误传辨析

说法判定依据
「龙芯后续拓展出 SW-64 指令集，申威基于 Alpha 拓展出 LoongISA」错误，恰好写反龙芯 = LoongArch（早期 MIPS）；申威 = SW64（源于 Alpha）。见 CSDN 文章中出现的错置，与厂商公开资料、架构标识 loongarch64 / sw_64 不符
「龙芯早期基于 MIPS，因此不算自主」片面判断依据是当前指令集定义权与持续演进能力，LoongArch 为自主定义；但历史授权链路仍应在供应链审查中如实披露
「六大 CPU 都实现了 100% 自主可控」错误三条路线的授权模式与可控程度明显不同，见上表
「某架构已获得 ARMv9 永久授权」存疑未见官方确认；行业分析普遍作相反判断，引用须标注「业界判断」

3.2 产业侧背景

  • 有媒体引述数据称 2025 年中国 AI 服务器市场交付约 400 万颗 AI GPU，国产芯片占比达 41%；摩根士丹利预测 2030 年中国 AI 芯片市场约 670 亿美元、国产有望满足约 76% 需求〔C，媒体转述，预测值〕。
  • 2026 年国产算力竞争焦点从单卡转向「超节点」与系统级方案，智能算力规模快速增长〔C，行业会议报道〕。
  • 「AI + 信创」的双向融合：一端是智算基础设施进入关基与政务采购视野，另一端是 AI PC / 智能体被纳入终端 OS 能力叙事。

辨析：有报道称「9 款 AI 芯片全部评定为最高安全可靠等级（Ⅰ 级）」〔C，重庆日报转载稿〕，但同期其他报道与 2026 年第 1 号公告的语义均表明 Ⅱ 级高于 Ⅰ 级（HarmonyOS V1.0 获 Ⅱ 级被报道为「首个达到该等级的国产桌面 OS」）。「Ⅰ 级为最高等级」是错误表述，详见 06 §4.3 与 09。

4. 整机、固件与外设：容易被漏掉的层

信创审计中，「全栈国产」的失分点常在整机内部而非 CPU 型号：

环节风险点核查要点
电源管理芯片、网络 PHY、时钟、内存接口部分「国产化设备」仅更换主 CPU，关键元器件仍为进口供应链，难以通过高标准审计〔C，工业领域报道〕要求提供 BOM 层级来源与供应链溯源
BIOS / UEFI / BMC固件自主程度、远程管理接口、默认口令、漏洞响应固件是否可自主更新、是否有安全启动与度量
板卡与驱动国产 OS 下驱动缺失或仅提供闭源二进制驱动是否提供目标架构版本、是否有长期维护承诺
可信计算TPCM/TCM 模块、可信度量链是否对接等保与密评要求
打印机主控芯片V3.0 已将其纳入测评对象关注后续公告批次
工业环境适应宽温、抗振动、电磁兼容、车载/户外/电网工况参数是否匹配实际工况，而非仅看 CPU 型号

结论：选型时要求供应商提供端到端适配清单 + BOM 溯源 + 压测报告，比只看 CPU 品牌更能反映真实国产化程度。

5.2 「产量自给率 70%」与「光刻机 <1%」并置

有报告引用高盛数据称中国集成电路产量自给率约 70%（2010 年约 38%），同时强调光刻设备是制约完全自主的核心瓶颈〔B，券商转引〕。两者不矛盾：

  • 产量自给率衡量的是芯片颗数 / 产值层面的供给规模，主要由成熟制程与封测拉动；
  • 设备国产化率衡量的是制造能力的自主程度，决定先进制程上限。

只引前者会高估可控水平，只引后者会低估产业规模。正确表述必须成对出现。

5.3 政策与资本

  • 大基金三期注册资本 3440 亿元，投向设备、材料、零部件等卡脖子环节〔B/C〕。
  • 工信部在 2026 年全国电子信息制造业高质量发展行业会议提出加快促进 RISC-V 产业发展；《电子信息制造业发展「十五五」规划》将 RISC-V 研发与产业化列入任务〔B/C，需以正式发布文本为准〕。
  • 「十五五」规划建议把集成电路列为全链条攻关首位领域〔A，gov.cn〕。

6.2 三大约束

  1. 产能：晶圆代工资源向头部倾斜，中小设计企业排产优先级低，出现「手握六万片订单、仅交付两三万片」的现象〔B/C，证券日报报道〕。
  2. 扩展碎片化：各家自定义扩展互不兼容，形成技术「方言」，削弱软件可移植性——这与信创整体面临的碎片化问题同构。
  3. 软件生态：编译器、操作系统、中间件、上层应用对 RISC-V 的支持深度仍不及 aarch64；服务器级落地刚起步。

判断：RISC-V 在 IoT、车规、边缘 AI、专用加速等新增场景具备结构性机会；在通用服务器与桌面替代上，中短期内仍是补充路线而非主流替代路线。把它直接列为「第七条信创 CPU 路线」为时过早。

8. 本章小结

  • 六家厂商、三条技术路线构成「迁移成本 × 自主程度 × 演进风险」的三角取舍，没有全局最优解；选型的硬约束往往是闭源组件与驱动，而非 CPU 峰值性能。
  • 龙芯 = LoongArch、申威 = SW64，网络资料中常见把两者写反；ARMv9 授权状态属业界判断而非官方确认。
  • 2026 年第 2 号公告首次把 AI 训推芯片纳入安全可靠测评（9 款，均 Ⅰ 级）；未上榜不代表不合格，测评为自愿申请。
  • 整机内部的电源管理芯片、网络 PHY、BIOS/BMC、驱动与打印机主控芯片，是「全栈国产」审计中最常见的失分点。
  • 上游半导体的正确图景是「产量自给率约 70%」与「先进制程光刻机不足 1%」并置；EDA、材料、高端 IP 仍是主要约束。
  • RISC-V 在新增场景有结构性机会，但产能、扩展碎片化、软件生态三大约束决定其短期是补充路线。
