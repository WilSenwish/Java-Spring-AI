# 信创（信息技术应用创新）研究总纲

> 调研基准日：**2026-11-05**。本套文档为静态研究成果，政策、测评公告、市场数据均随时间变化，引用前请按附录的核验路径复核最新版本。
>
> 文档定位：面向技术决策者、架构师、采购与合规人员、ISV、研究人员的**结构化知识底座**，不是产品宣传材料，也不构成投资建议。

---

## 一、一句话结论

信创已经越过「能不能替代」的阶段，进入「替代得对不对、用得好不好、能不能持续演进」的深水区。其本质不是把国外产品换成国产产品，而是**在采购制度、测评体系、技术栈、工程方法、产业组织五个层面同时重建一套可验证、可审计、可迭代的数字基础设施供给体系**。

2025—2026 年出现的三个制度性变化，决定了当前阶段的性质：

1. **国办发〔2025〕34 号**（2026-01-01 施行）首次在政府采购中给出「本国产品」的可操作定义与 20% 价格评审优惠，把支持政策从「目录思维」转为「标准思维」，并明确对国企、民企、外资企业一视同仁。
2. **《安全可靠测评工作指南 V3.0》**（2025-07）把测评对象从 CPU/OS/数据库扩展到 AI 训推芯片与打印机主控芯片；2026 年第 2 号公告首次公布 AI 芯片结果。
3. **国务院令第 834 号《国务院关于产业链供应链安全的规定》**（2026-03-31 公布施行）把供应链安全从政策表述升格为行政法规，并确立关键领域清单、风险监测预警、安全调查与反制制度。

与之并行的是尚未解决的结构性矛盾：**市场规模口径极度混乱、底层环节国产化率仍低、生态碎片化导致适配成本倍数增长、伪自主与套壳难以识别**。本套文档对这四类问题均给出可核查的辨析，而非回避。

## 三、十条核心结论（速览）

1. **信创是体系建设，不是采购替换。** 完整链条是「芯片 → 固件/整机 → 操作系统 → 数据库/中间件 → 云 → 应用 → 安全 → 服务」，任何一层未打通都会在生产环境暴露为兼容或性能问题。

2. **「国产化率」必须带口径，且不同指标不可并列成同一个「率」。** [03](./03-产业链全景与技术栈.md) §4 给出的可核查四行是：CPU 全市场出货 1%—2%、信创采购口径约 28%—30%、**集成电路产量自给率约 45%—70%（含成熟制程与各类芯片，不是 CPU 国产化率）**、先进制程光刻机设备国产化率不足 1%；另有 [08](./08-产业经济与生态格局.md) §3.2 的「鲲鹏约 60%」是**单一厂商在信创采购中的份额**，属厂商格局而非国产化率。脱离口径谈渗透率没有意义。

3. **市场规模数字不可直接比较，且必须同年相比。** [08](./08-产业经济与生态格局.md) §1.1 的同年跨度是：**2025 年 1.2 万亿 → 3 万亿元（约 2.5 倍）**、**2026 年 0.85 万亿 → 2.66 万亿元（约 3.1 倍）**。8500 亿元是 **2026 年预测**，3 万亿元是 **2025 年信创软件口径**，二者跨年份、跨口径，不能拼成同一年的倍数差。差异主要来自统计边界、口径类型、实绩/预测与营销放大。

4. **34 号文不是「信创强制目录」。** 它定义的是「在中国境内生产 + 组件成本占比」，**不含自主知识产权或指令集要求**，且明确不得指定品牌、不得按所有制或投资者国别歧视。把它解读为「必须买国产 CPU」是对原文的误读（详见 02）。

5. **安全可靠测评 ≠ 准入目录。** 官方指南明确「自愿平等、客观公正，由企业自愿申请，结果由企业和用户自主选择使用」；公告是**测评结果公告**，不是「核心准入目录」。所有把 2026 年第 1 号公告称作「信创核心准入目录（第 1 号）」的说法均为自媒体讹误（详见 06、09）。

6. **四套合规体系互不替代。** 等保 2.0（系统整体防护）、密评（密码用得对不对）、安全可靠测评（产品与厂商的全生命周期可靠性）、信创适配认证（软硬件兼容互通）各管一段，一张证书不能覆盖另一张（详见 06）。

7. **技术路线没有最优解，只有取舍。** x86 兼容路线迁移成本最低但受授权约束；ARM 路线生态成熟但受架构版本演进约束；自主指令集路线长期可控性最强但生态需从零积累。选型应按业务负载、闭源组件可用性、供应保障三要素定（详见 04）。

8. **迁移的主要工作量在数据库方言与闭源依赖，不在 CPU。** JVM 屏蔽了大部分指令集差异；真正导致工期失控的是 SQL 方言、存储过程、无 aarch64/loongarch64 版本的闭源 SDK 与监控 Agent、ActiveX/控件类组件（详见 07）。

9. **最大非技术风险是「伪自主」与生态碎片化。** 前者让「国产化率」报表产生虚假安全感，后者让适配成本随「芯片 × OS × 数据库」组合数呈倍数增长。834 号令、46 号令第十二条（科技创新追责情形）与按技术路线分包招标分别从不同侧回应这两类风险（详见 09）。

10. **下半场竞争是「定义权」而非「替代率」。** 判断产业是否成熟，应看开源根社区活跃度、根技术（内核/引擎/编译器/EDA）自主度、标准话语权与商业市场中标率，而不是看行政采购完成比例（详见 10）。

## 四、证据规则与数据口径声明

本套文档对每条关键事实标注**证据等级**，读者可据此决定引用强度：

| 等级 | 定义 | 典型来源 | 使用建议 |
|---|---|---|---|
| **A** | 一手权威原文 | gov.cn、itsec.gov.cn、nsstec.org.cn、sasac.gov.cn、oscca.gov.cn、国家标准全文、上市公司公告/年报、厂商官方公告 | 可直接引用，需核对版本号与生效日期 |
| **B** | 权威机构研究结论 | 中国信通院、赛迪顾问、IDC、艾瑞、沙利文、亿欧智库、第一新声、券商研究所 | 引用须注明「机构 + 报告名 + 年份 + 口径」；若系二手转述，标注「转引」 |
| **C** | 行业媒体 / 厂商营销稿 / 技术博客 | 行业门户、公众号、CSDN、厂商解决方案页 | 仅作线索，须交叉验证；不得单独作为结论依据 |
| **D** | 已识别的讹误或无法证实 | 见 09 误传辨析 | 明确标注为「不成立 / 存疑」，禁止当作事实引用 |

三条硬性规则：

1. **时间基准**：所有「当前」「截至目前」均指 2026-11-05。政策以施行日期而非发布日期判断效力。
2. **数字必带口径**：任何百分比、金额、渗透率都附「统计范围 + 时点 + 来源等级」。缺少口径的数字一律标注「口径不明」。
3. **预测与实绩分离**：2026 年及以后的规模、渗透率均为机构预测，不视为既成事实。
4. **C 级数字默认「待核实」**：凡 C 级（或 B 级转引但未披露统计年份/分母）的百分比、金额、份额，正文加「待核实」或统一声明，不得单独作为结论或招标依据。

### 本套文档已识别并纠正的主要误传

| 误传 | 事实 | 详见 |
|---|---|---|
| 「2026 年 1 月发布信创核心准入目录（第 1 号），覆盖 CPU/数据库」 | 实际是《安全可靠测评结果公告（2026 年第 1 号）》，仅含 5 款操作系统；CPU/数据库结果分属其他批次；且测评为自愿性质 | 06 / 09 |
| 「安全可靠 I 级是最高等级」 | 公告体系中 Ⅱ 级高于 Ⅰ 级；2026 年第 1 号中 HarmonyOS V1.0 为 Ⅱ 级并被报道为「首个达到该等级的国产桌面 OS」 | 06 / 09 |
| 「Ⅰ 级≈等保二级/三级，Ⅱ 级≈等保三级/四级」 | 官方未公开此类对应关系，系自媒体类比；两套体系评价对象不同 | 06 / 09 |
| 「国资委 46 号令明确将采购伪国产列为首要追责情形」 | **部分失实**：第十二条「科技创新」第（一）项确有「通过制售、采购伪创新伪国产产品，虚假完成攻关任务」；错在「首要」、错在归入购销管理（实为第九条）、错在泛化为凡采购即追责 | 02 / 09 |
| 「龙芯拓展出 SW-64，申威基于 Alpha 拓展出 LoongISA」 | 恰好写反：龙芯 = LoongArch（早期 MIPS），申威 = SW64（源于 Alpha） | 04 / 09 |
| 「国办发 34 号 = 政府采购必须买国产 CPU/OS」 | 原文为「境内生产属性改变 + 组件成本占比」，且明确平等对待各类经营主体、不得指定品牌 | 02 / 09 |
