## 1. 两种分层模型及其用途

产业界同时流通两种分层，混淆会导致口径错误。

### 1.1 四层模型（产业统计口径）

| 层 | 内容 | 典型品类 |
|---|---|---|
| 基础硬件 | 芯片、整机、固件、存储、网络、外设 | CPU、服务器、PC、BIOS/BMC、SSD、交换机、打印机主控芯片 |
| 基础软件 | 操作系统、数据库、中间件、云平台、开发工具链 | 桌面/服务器 OS、集中式/分布式 DB、应用服务器、消息中间件、容器平台、JDK/编译器 |
| 应用软件 | 办公软件、经营管理软件、行业应用 | WPS/永中、OFD 版式、ERP/财务、核心业务系统、行业 ISV 方案 |
| 信息安全 | 贯穿全栈的防护、认证、密码、终端与边界安全 | 等保/密评相关产品、国密组件、终端安全、零信任、安全服务 |

这是研究机构统计「信创产业规模」时常用的分类，**也是市场规模口径混乱的源头之一**：是否把整机、半导体上游、系统集成服务、安全服务计入，会让总量相差数倍（见 [08](./08-产业经济与生态格局.md)）。

### 1.2 六层技术栈模型（工程口径）

```
L6  安全与合规      等保 / 密评 / 国密 / 安全可靠测评 / 适配认证 / 审计
L5  应用层          办公 / 经营管理 / 行业核心系统 / 前端与控件 / 外设交互
L4  数据与平台层    数据库 / 中间件 / 消息队列 / 缓存 / 大数据 / 容器与云管
L3  操作系统层      桌面 OS / 服务器 OS / 内核 / 文件系统 / 驱动 / 桌面环境
L2  整机与固件层    服务器 / PC / BIOS(UEFI) / BMC / 板卡 / 整机适配
L1  芯片层          CPU / AI 芯片 / GPU / 存储主控 / 网卡 / 打印机主控芯片
        ↑ 上游：指令集与 IP、EDA、晶圆制造、封装测试、材料与设备
```

**工程含义**：迁移问题几乎总是出现在**层间接口**，而不是层内。典型如 L1→L3 的架构标识（`x86_64` / `aarch64` / `loongarch64` / `sw_64`）、L3→L4 的系统调用与 glibc 版本、L4→L5 的 SQL 方言与 Jakarta EE 实现差异、L5→L6 的国密改造与 ActiveX 控件替代。详见 [07](./07-行业落地与工程迁移方法论.md)。

## 3. 价值分布与壁垒梯度

### 3.1 壁垒从下往上递减、参与者从下往上递增

| 层级 | 技术壁垒 | 资本/周期 | 参与者数量 | 议价能力 |
|---|---|---|---|---|
| 半导体上游（EDA/设备/材料/先进制程） | 极高 | 极长 | 极少 | 高但受制于外部 |
| 芯片设计（CPU/AI） | 极高 | 长 | 6—10 家主路线 | 高 |
| 操作系统（内核/发行版） | 高 | 长 | 少数 | 高 |
| 数据库（引擎） | 高 | 长 | 十余家有竞争力 | 中高 |
| 中间件 | 中高 | 中 | 5—8 家主要 | 中 |
| 云平台 / 整机 | 中 | 中 | 十余家 | 中 |
| 行业应用 / 安全 / 服务 | 中低 | 短 | 数百家 | 低（价格竞争） |

**结构性结论**：越靠近底层，国产化率越低、替代难度越大、单位价值越高；越靠近应用，替代完成度越高但利润越薄。这解释了为什么「规模数字很大、底层渗透率很低」可以同时成立〔证据等级 B，信通院白皮书转述〕。

### 3.2 结构变化：从硬件主导到软硬均衡

多份研究给出一致方向：硬件替代占比从 2022 年约 68% 降至 2025 年约 52%，软件与服务占比上升，数据库、中间件、云平台等基础软件国产化进程加速〔B，中国信通院《2025—2026 年中国信息技术应用创新产业发展白皮书》转述〕。

**注意口径**：这里的「占比」指信创替代支出结构，不是整个 IT 市场结构；且不同报告的分母不同，仅可用于判断方向，不宜作精确比较。

| 工业软件 | 约 25%；CAD 外资约 85%、CAE 外资超 90% | 细分市场 | B/C | 最大短板之一 |
| 光刻机（先进制程） | 不足 1% | 设备国产化率 | B（券商转引） | 与「产量自给率 70%」并置才是完整图景 |

**使用守则**（与 [README 证据规则](./README.md) 一致）：

1. 引用任何百分比必须写明「口径 + 时点 + 来源」。
2. 「产量自给率」「信创采购份额」「全市场占有率」「替代率」是四个不同概念，禁止互换。
3. 预测值（如 2026 年、2027 年渗透率）与实绩值分开列示。
4. 涉及决策时，优先使用**本项目自身盘点数据**，行业平均仅作背景。
5. 本表 B/C 级数字多为二手转引且**常缺统计时点**，凡未标注年份者一律视为「待核实」，不得单独作为结论依据。

## 5. 技术栈组合：碎片化的成本来源

### 5.1 组合爆炸

若按「CPU 路线 × OS 发行版 × 数据库 × 中间件」计算，理论组合数为：

```
4 类 CPU 架构 (x86_64 / aarch64 / loongarch64 / sw_64)
× 6+ 商业/云 OS 发行版
× 10+ 数据库产品
× 5+ 应用服务器
× 各产品的多个大版本与内核版本（4.19 / 5.10 / 6.6 …）
```

即便收敛到主流组合（如「鲲鹏+麒麟+达梦+东方通」「海光+统信+GaussDB+宝兰德」「龙芯+麒麟+达梦+TongWeb」），一个需要覆盖多行业客户的 ISV 仍要维护数套适配矩阵与回归测试流水线。**适配成本近似随组合数线性甚至超线性增长**，这是 [09](./09-风险挑战与批判性视角.md) 讨论的生态碎片化风险的量化根源。

### 5.2 主要生态阵营

| 阵营 | 核心组合 | 支撑方 | 特点 |
|---|---|---|---|
| **PK / PKS 体系** | 飞腾（Phytium）+ 麒麟（Kylin），PKS 加入安全（Security） | 中国电子 CEC | 政务与关基市场积累深 |
| **鲲鹏计算生态** | 鲲鹏 + openEuler + openGauss / GaussDB + 华为云 | 华为 | 全栈闭环、开源社区外溢强 |
| **C86 路线** | 海光 / 兆芯 + 主流 Linux 发行版 | 海光、兆芯生态伙伴 | x86 兼容、迁移成本最低 |
| **自主指令集路线** | 龙芯 LoongArch / 申威 SW64 + 适配 OS | 龙芯中科、申泰 | 可控性最高、生态需自建 |
| **开源根社区** | openEuler / OpenAnolis / OpenHarmony / openGauss | 开放原子开源基金会等 | 降低重复造轮子，跨厂商共用底座 |
| **云厂商一云多芯** | 统一云管 + 异构算力池 | 华为云、天翼云、中国电子云、EasyStack、ZStack | 以平台层屏蔽差异 |

**注意**：阵营是**产业协作叙事**，不是技术标准，也不构成排他关系。同一厂商常同时参与多个阵营，招标中按技术路线分包（C86 / ARM / 自主指令集）正是对多元并存的制度化。

### 5.3 全栈协同 vs 组合式适配

| 维度 | 组合式适配（「加法」） | 全栈协同（「乘法」） |
|---|---|---|
| 目标 | 各层分别能安装、能启动 | 联合调优后的生产级性能与稳定性 |
| 验证方式 | 功能性兼容清单 | 端到端压测、故障注入、长稳压测 |
| 责任边界 | 各厂商各自负责 | 需明确牵头方与联合问题定位机制 |
| 典型失败 | 高并发下 IO 阻塞、内存泄漏、内核崩溃 | — |
| 审计视角 | 「纸面兼容」易被判为不达标 | 能承载业务才通过 |

有行业文章把组合式适配、内核级套壳、闭源依赖列为验收「三大死穴」〔C，行业评论〕。这类表述虽非官方条文，但与 [06](./06-安全合规与测评认证体系.md) 中「测评关注研发单位与持续发展」的导向一致，可作为自查视角。

## 6. 上游：必须一并看到的半导体约束

信创的「全栈可控」向上追溯会触到当前最硬的约束。多份 2026 年研究给出的分层图景〔B/C，券商与行业会议转引，数字口径需逐一核对〕：

| 环节 | 状态 | 主要约束 |
|---|---|---|
| 成熟制程（28nm 及以上） | 产能与利用率较高，设备国产化率可达 50%+ | 结构性内卷、价格竞争 |
| 先进制程（7nm 及以下） | 受 EUV 等约束，量产能力受限 | 良率、成本、设备可得性 |
| 设备 | 刻蚀/清洗国产化率 **50%—65%**（不同来源有 55%—65% 的较窄区间，全站统一取宽区间），薄膜沉积 25%—30%，光刻机整体不足 1%，量测/离子注入个位数至低两位数 | 高端设备出口管制 |
| 材料 | 整体约 15%；12 英寸大硅片约 10%、高端光刻胶 <10%、电子特气 15%—30% | 认证周期长 |
| EDA | 整体 12%—20%；模拟全流程突破，数字后端 <20%，5nm 以下 <5%；亦有厂商称工具覆盖率提升至 85%（**覆盖率≠国产化率**） | 三巨头仍占主导 |
| 高端 IP / HBM | CPU/GPU/NPU 高性能 IP 依赖海外 | 供应与授权双重风险 |
| 先进封装 | 国产化程度最高、追赶最快（Chiplet / HBM 相关） | 相对优势环节 |

**大基金三期**注册资本 3440 亿元，投向明确指向设备、材料、零部件等卡脖子环节〔B/C，行业转述〕。

**关键辨析**：「中国芯片自给率约 70%」是**产量口径**，与「先进制程光刻机国产化率不足 1%」并不矛盾——前者说明规模铺开，后者说明纵深未打通。把两者并列，才是完整的产业图景；只引其中一个都会导出错误结论。

## 7. 下游：服务层决定交付质量

服务和集成环节常被产业链图谱忽略，但它是从「产品可用」到「系统可用」的转化层：

- **适配测试**：CMA/CNAS 第三方机构在指定国产环境组合下做功能、性能效率、信息安全性测试，依据常见为 GB/T 25000.51-2016。
- **兼容互认证**：由 OS/CPU/数据库厂商发放的双向证明，用于生态合作与联合方案。
- **迁移实施**：兼容性预检、双轨并行、数据迁移、灰度切换、回退演练（详见 [07](./07-行业落地与工程迁移方法论.md)）。
- **运维与培训**：国产栈日常运维、监控、补丁管理；人才缺口是实际交付瓶颈（见 [08](./08-产业经济与生态格局.md)）。
- **验收与合规**：试运行报告中的适配调优专项、安全测评报告、声明函归档（见 [02](./02-政策脉络与法规体系.md) §6、[06](./06-安全合规与测评认证体系.md)）。

**责任设计建议**：合同中明确「适配问题清单 + 解决时限 + 联合定位机制 + 版本升级后的重测责任」，避免各层厂商互相推诿。

## 8. 本章小结

- 四层模型用于产业统计，六层模型用于工程排障，二者不可混用。
- 壁垒与价值自下而上递减、参与者自下而上递增；底层渗透率低与产业规模大并不矛盾。
- 所有国产化率数字必须带口径；「产量自给率」「信创采购份额」「全市场占有率」「替代率」是四个不同概念。
- 生态碎片化的成本根源是「架构 × OS × 数据库 × 中间件 × 版本」的组合爆炸；一云多芯与开源根社区是两条主要收敛路径。
- 上游半导体约束决定「全栈可控」的现实边界；下游服务层决定交付质量，二者都必须在产业链视图内。
