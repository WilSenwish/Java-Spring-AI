**同年（2025）跨度：1.2 万亿 → 3 万亿，约 2.5 倍；同年（2026）跨度：0.85 万亿 → 2.66 万亿，约 3.1 倍。**

### 1.2 差异的五个来源

1. **统计边界**：是否计入服务器/PC 整机、是否计入半导体上游、是否计入系统集成与运维服务、是否计入通用 IT 支出。
2. **口径类型**：「产业规模」（供给侧产值）、「市场规模」（需求侧支出）、「软件市场规模」、「硬件市场规模」四种。
3. **实绩 vs 预测**：大量被当作「2025 年已达」引用的数字，实际是 2024 甚至更早做出的**预测值**。
4. **基准年与增长率复算**：同一机构不同版本报告会对历史基数回溯调整。
5. **营销性放大**：产业链上下游稿件倾向于引用更乐观的口径以支撑叙事。

### 1.3 使用建议（可直接写入研究报告的方法论）

> **结论：不存在一个可直接引用的「信创市场规模」。任何引用必须绑定「机构 + 报告全名 + 年份 + 口径定义 + 实绩/预测」。**

推荐采用**分层口径**替代单一总量：

| 层 | 定义 | 用途 |
|---|---|---|
| L1 核心信创软硬件 | CPU/OS/DB/中间件/整机/安全产品的信创相关采购额 | 最窄，适合厂商 TAM 测算 |
| L2 信创相关 IT 支出 | L1 + 应用改造、迁移服务、集成、运维、培训 | 适合项目预算与人力规划 |
| L3 泛自主可控产业 | L2 + 半导体上游、工业软件、算力基础设施 | 适合宏观产业叙事 |

**跨机构数字只能用于判断方向（增长/结构变化），不能用于计算增速、份额或 CAGR**——用不同口径的两年数字相减得到的增长率是伪精确。

### 1.4 相对可靠的结构性判断

虽然总量不可比，但多个来源一致指向同一方向，可信度高于总量：

- 硬件替代占比从 2022 年约 68% 降至 2025 年约 52%，软件与服务占比上升〔B，信通院白皮书转述〕。
- 驱动力从「政策单轮」转向「政策 + 市场双轮」，市场化驱动占比提升〔B/C〕。
- 2026—2027 年被普遍视为央国企与重点行业替代目标的**关键验收期**〔C，行业共识性表述，注意 79 号文未公开全文，见 [02](./02-政策脉络与法规体系.md) §5.1〕。

## 2. 驱动力与资金面

### 2.1 三阶段驱动模型

| 阶段 | 主要驱动 | 采购逻辑 | 厂商竞争维度 |
|---|---|---|---|
| 政策驱动（~2022） | 试点与行政部署 | 完成替代任务 | 入围、适配清单 |
| 政策 + 合规（2023—2025） | 79 号文转述目标、安全可靠测评、采购需求标准 | 满足比例与资质 | 测评等级、案例、交付能力 |
| 政策 + 市场（2025—） | 34 号文、十五五、企业自身数字化需求 | TCO、性能、体验、可持续 | 生态厚度、根技术、服务 |

### 2.2 需求侧的三根支柱

1. **政府采购**：34 号文给出 20% 价格评审优惠与声明函机制，「十五五」建议明确「加大政府采购自主创新产品力度」，形成稳定的需求基本盘〔A〕。
2. **国资央企与关基行业**：内部部署目标 + 关基合规义务 + 834 号令供应链安全要求〔A/B〕。
3. **存量替换窗口**：CentOS 停服、Oracle 维保成本上升、老旧版本补丁收敛、外资厂商部分产品线战略调整，共同构成经济性动机〔C，行业观察〕。

### 2.3 资金面与支付能力

有上市公司公告援引：2025 年超长期特别国债增加 3000 亿元、10 万亿化债方案落地，认为有助于改善地方政府与国企信创采购的支付能力、释放此前因资金紧张延迟的需求〔B，上海证券报信息披露〕。这属于**公司管理层对经营环境的判断**，不是政策对信创的专项拨款，引用时须区分。

**风险侧**：地方财政支付节奏会直接影响项目回款与交付转化，是厂商现金流管理的关键变量；甲方则应关注「预算到位但运维预算不足」导致的长期 TCO 缺口。

## 3. 资本市场与竞争格局

### 3.1 资本市场表现（时点数据，不构成投资建议）

检索到的板块行情数据显示：2025 年全年「信创」概念板块（代码 02GN2043）区间涨跌幅约 +30.86%，「国产操作系统」板块约 +19.27%；同期振幅分别约 56.97% / 47.56%〔B，行情数据源，检索时点 2026-11-05〕。这类数据时效性强，**仅供说明板块波动特征，不宜写入长期结论**。

代表性上市公司（按产业链层）：海光信息、龙芯中科、寒武纪、中科曙光、浪潮信息、达梦数据、麒麟信安、东方通、宝兰德、普元信息、金山办公、用友网络、金蝶国际、奇安信等〔B，公开市场信息〕。

### 3.2 分层竞争格局

| 层 | 格局 | 代表数据（转引，口径需核对） | 竞争焦点 |
|---|---|---|---|
| CPU | 多路线分层 | 有资料称鲲鹏约 60%、海光约 25%、飞腾约 15%，其余各 1%—2%（信创采购口径）；另有资料称六大厂商三档分化 | 路线收敛、采购分包规则、生态 |
| 桌面 OS | 双寡头 + 新进入者 | 银河麒麟约 45%、统信 UOS 约 38%（某口径）；另有稿件称麒麟信创桌面约 70% | 生态厚度、行业纵深、鸿蒙入局 |
| 服务器 OS | 商业发行版 + 开源系 | openEuler 系份额超 57%（某口径）；2026 年新增份额超 50%（另一口径） | 云场景、内核版本、社区活跃度 |
| 数据库 | 最胶着 | 达梦/人大金仓/OceanBase 合计超 35%（某口径）；分布式事务型市场 OceanBase 20.2%、阿里云 17.9%、腾讯云 16.5%、华为云 14.3%、金篆信科 10.1%（沙利文某报告口径）；国产份额 52.3% / 71%（不同口径） | 核心系统案例、迁移工具链、HTAP |
| 中间件 | 一超多强 | 东方通超 30%、普元约 15%、宝兰德约 12% | Jakarta EE 兼容、云原生 |
| 应用软件 | 办公集中、行业碎片 | WPS 主导；金融 IT 第一梯队多家并存 | 行业 Know-how、交付网络 |
| 信息安全 | 最分散 | 多家厂商各据细分 | 全栈适配覆盖、等保/密评能力 |

**规律**：越靠近底层集中度越高、越靠近应用越分散；但**每一层的份额数字都高度依赖口径定义**，跨报告比较无效。

### 3.3 采购机制改革

- 有资料称 2025 年起信创工委会推动采购标包按 **C86（海光/兆芯）、ARM（鲲鹏/飞腾）、自主指令集（龙芯/申威）** 三大技术路线强制划分，每标包至少引入 3 家厂商；北京按 LoongArch/ARM 分包，杭州按三路线招标〔C，行业转述，**须以具体招标文件核实**〕。
- 制度意图：抑制品牌捆绑与寡头绑架，让竞争回到性能、价格、生态、服务。
- 与「十五五」建议中「消除招标投标、政府采购等方面壁垒」「破除地方保护和市场分割」形成呼应〔A〕。

## 4. 区域集群与人才

### 4.1 区域格局

| 集群 | 核心载体 | 特点 |
|---|---|---|
| 京津冀 | 天津滨海高新区「中国信创谷」、北京、河北 | 产业链最完整；飞腾、麒麟、海光、中科曙光等集聚；先进计算与关键软件（信创）海河实验室；有资料称集群目标 2027 年规模 3 万亿元（**目标值非实绩**） |
| 长三角 | 上海、杭州、南京、无锡 | 芯片设计、EDA、金融信创、云与数据库 |
| 粤港澳 | 深圳、广州、东莞 | 整机、终端、开源鸿蒙生态、AI 芯片 |
| 中西部 | 成都、武汉、西安、兰州、贵州 | 依托「东数西算」承接算力与制造；成都/武汉为信创岗位核心节点 |
| 其他节点 | 山西长治（整机产能）、福建（政策与园区）、湖南（自主安全计算创新中心）、广西（五级服务网络） | 差异化卡位 |

公开数字示例：天津「中国信创谷」整体产业规模超 800 亿元、聚集信创生态企业超千家；另有资料称天津信创产业链规模超 1200 亿元、2024 年前 10 个月达 1109 亿元、天津高新区研发经费投入强度超 7%〔B/C，多源且口径与年份不一，**仅作密度说明**〕。有资料称京津冀、长三角、粤港澳三大集群贡献全国 70% 以上信创产值，另有报告称 65% 以上〔C，口径不明〕。

**判断**：集群数据多用于地方招商叙事，统计边界（是否含半导体、是否含软件全行业）差异极大，不宜用于横向排名。

### 4.2 人才缺口

| 指标 | 转引数值 | 口径 |
|---|---|---|
| 信创人才缺口 | 超 100 万人 / 约 60 万人 | 不同机构、不同定义（是否含适配、运维、集成） |
| RISC-V 专业人才 | 年供给不足 2 万、需求超 10 万 | 某人才白皮书口径 |
| 半导体全行业人才缺口 | 超 20 万 | 2026 年行业会议引述 |
| 高校师资 | 能独立开设 RISC-V × OpenHarmony 完整课程的教师估计不足 20 人 | 某人才白皮书估计值 |
| 薪资溢价 | 信创岗位较传统 IT 高 20%—40% | 行业观察 |

〔以上均为 B/C，估计值居多，不构成可靠统计〕

**相对可靠的结构判断**：

- 瓶颈不在毕业生数量，而在**师资、教材与真实项目训练**；八成以上 IT 人员长期学习海外技术栈，进入信创项目需补课〔C〕。
- 岗位高度集中于**北京、深圳、上海、成都、武汉、杭州**，天津因四家龙头集聚为独立节点；经验可复用性依赖本地生态配套〔C〕。
- 订单班 / 产业学院（如鸿蒙订单班）能缓解底座岗位供给，但**架构师与规划管理师无法批量培养**〔C〕。
- 人才短板直接转化为交付风险：适配问题清单、性能调优、故障定位都依赖有国产栈经验的人。

## 5. 商业模式与 TCO

| 成本项 | 传统栈 | 信创栈的变化 |
|---|---|---|
| 软件许可 | Oracle/Windows/IBM 按核/按用户 | 转向订阅或一体机；部分场景许可成本下降 |
| 硬件 | 通用 x86 规模效应 | 多架构小批量采购，单价与备货周期承压 |
| 迁移实施 | — | **新增的一次性大头**：预检、代码与 SQL 改写、双轨并行、压测、演练 |
| 适配认证 | — | 新增：测试报告、评估证书、互认、每三年重测 |
| 合规 | 等保 | 叠加密评、安全可靠测评核验、声明函、SBOM |
| 运维 | 成熟工具链与人才池 | 工具链替换、培训、多架构镜像与 CI、监控 Agent 适配 |
| 隐性成本 | — | 二次选型风险、性能差距带来的扩容、生态问题排障时长 |

**结论**：以「替换采购单价」评估信创项目会系统性低估 TCO。合理的评估口径是 **5 年全生命周期成本**，且必须计入迁移、认证、双轨、培训与重测。有案例披露三年节约许可与维保约 1.7 亿元〔C，厂商披露〕，但这类数字不含迁移投入，不可直接用于投资回报测算。

## 6. 国际比较：其他经济体怎么做

> 目的不是简单类比，而是说明「政府采购 + 供应链安全」是各国通用制度工具，但**设计逻辑差异显著**。

### 6.1 美国：价格优惠 + 国别清单 + 安全认证三线并行

| 工具 | 机制 | 关键参数（2026 时点） |
|---|---|---|
| **Buy American Act (BAA)** | 国货价格评审优惠 + 国内组件成本比例 | 非本国报价加价：大企业 20%、小企业 30%、国防部 50%；国内组件比例门槛 2024—2028 年 65%，2029 年起升至 75%（有限情形回退 55%） |
| **Trade Agreements Act (TAA)** | 超过门槛的采购改用「指定国家」原产地规则 | 2026—2027 年货物门槛约 174,000 美元；中国、俄罗斯、印度等**不在指定国家名单**；「实质性改变」要求高于重新包装/贴标/简单组装 |
| **NDAA Section 889** | 按**厂商**禁止特定电信与视频监控设备 | 无金额门槛，问的是「谁造的」，与 TAA 的原产地规则独立 |
| **FIPS 140-3 / Common Criteria / FedRAMP / CMMC** | 密码模块、产品安全、云授权、国防供应链信息安全 | 各管一段，一条产品线可过其一而不过另一 |

〔B，Federal News Network、USFCR、律所与合规服务商解读；具体阈值以 FAR 25.4 与各年调整为准〕

**值得注意的对照**：

- **中国 34 号文**采用「境内生产 + 组件成本占比 + 20% 价格扣除」，并**明确对国企、民企、外资企业一视同仁、不得按投资者国别歧视**。
- **美国 TAA** 采用「指定国家清单」路径，直接以国别排除；BAA 则是价格优惠 + 国内成分比例。
- 两者都使用了「属性改变 / 实质性改变」这一反规避概念：34 号文列出五类不构成属性改变的细微操作；TAA 明确重新包装、贴标、简单组装不构成实质性改变。**这是制度设计上最值得对照的一点。**
- 倪光南院士 2016 年即建议参考美国《购买美国产品法》的「增值」准则识别「假国产」〔B，人民日报《中国经济周刊》〕，可见「反贴牌」是共通难题。

### 6.2 其他经济体（简述）

| 经济体 | 主要取向 | 与信创的可比点 |
|---|---|---|
| 欧盟 | WTO GPA 框架下的政府采购规则 + NIS2 网络安全义务 + 主权云/数字主权讨论 + EUCS 云安全认证 | 强调规则与认证，而非按国别强制替换；同样面临「自主可控 vs 开放市场」张力 |
| 俄罗斯 | 国产软件目录、国产 CPU（Elbrus / Baikal）与 Astra Linux 等 OS、关基国产化要求 | 与信创「目录 + 全栈替代」路径最相近，可作为「强制替代边界」的参照样本 |
| 印度、日韩等 | 政府采购本土偏好、半导体产业扶持、特定领域安全审查 | 多为产业政策 + 安全审查组合，缺少覆盖全栈的体系化测评 |

> 说明：本节为制度类型学对比，具体条款与现行状态需按各国官方法规逐项核实；不作价值判断。

### 6.3 对照结论

1. **工具是通用的**：价格优惠、原产地/成分规则、指定国家清单、安全认证、按厂商排除，各国都在用。
2. **中国的特殊性**在于把「全栈适配 + 产品级安全可靠测评 + 行业分层推进 + 五年规划需求牵引」组合成体系，且明确写入全国统一大市场约束。
3. **不能简单类比**「美国也搞国产替代所以信创无需讨论边界」——各制度的作用对象、覆盖范围与救济机制不同；[09](./09-风险挑战与批判性视角.md) 讨论的强制替代边界争议仍需独立判断。

## 7. 本章小结

- **2025 年信创市场规模的公开数字从 1.2 万亿到 3 万亿元不等，2026 年从 0.85 万亿到 2.66 万亿元不等**；差异来自统计边界、口径类型、实绩/预测与营销放大。唯一严谨做法是绑定「机构 + 报告 + 年份 + 口径 + 实绩/预测」，或改用 L1/L2/L3 分层口径。
- 结构性判断（硬件占比下降、驱动力转双轮、2026—2027 为关键验收期）比总量数字更可靠。
- 竞争格局呈「底层集中、应用分散」，但份额数字同样高度依赖口径；按技术路线分包招标是重要的采购机制变量。
- 区域集群与人才缺口的公开数字多用于招商/白皮书叙事，只可用于判断集聚方向；**真正的瓶颈是师资、真实项目训练与架构师供给**。
- TCO 必须按 5 年全生命周期计算，纳入迁移、认证、双轨、培训与三年重测成本。
- 国际比较显示「属性改变 / 实质性改变」是各国共用的反规避工具；中国 34 号文的显著特征是**平等对待各类经营主体**，与美国 TAA 的国别排除路径不同。
