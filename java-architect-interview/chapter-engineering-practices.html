工程化要点

从篇章、核心原理与场景导读的「工程化要点」去重提炼为平台可执行口径：发布、观测、容量、数据、缓存、治理、AI 与安全八组门禁。

24 工程化卡片 | 不计入题目总量 365 | ID 前缀 G

本篇与核心方法论并列：方法论回答「怎么想」，本篇回答「上线前必须守住哪些工程门禁」。卡片采用与方法论相同的三层结构（核心洞察 / 原理映射 / 工程表达），内容源自杀青导读，并可回链各篇章。

发布回滚与变更门禁

G01.01
发布三要素：灰度·卡点·回滚架构级
核心洞察

高风险变更默认按「分批放量 + 指标卡点 + 一键回滚」执行；回滚路径必须演练过。

原理映射

对应篇章工程化要点中的金丝雀、错误预算、配置/镜像/流量三维可退。

工程表达

变更单模板固定三要素；卡点未过不得扩量。

G01.02
配置变更当发布架构级
核心洞察

热更新与配置推送按发布管控：审批、灰度、快速关停与本地快照兜底。

原理映射

配置中心抖动不得拖垮核心链路；有毒变更可秒级关停。

工程表达

评审配置项时同步评审回滚开关与生效范围。

G01.03
框架与依赖升级门禁架构级
核心洞察

大版本升级用契约测试+金丝雀；弃用 API 与默认行为变化进回归清单。

原理映射

基线 BOM 由平台抬升，业务少私锁版本。

工程表达

「编译过了」不等于可上线。

可观测与排障证据链

G02.01
三支柱默认交付架构级
核心洞察

日志规范、指标、追踪随脚手架默认接入，禁止上线后补丁式接入。

原理映射

采样可解释可回放；告警绑定 Runbook。

工程表达

新服务验收检查三支柱是否齐活。

G02.02
排障标准动作架构级
核心洞察

固定：现象 → 分层/分区归因 → 采证（日志/指标/转储/profile）→ 动作 → 回滚条件。

原理映射

无证据调参视为违规。

工程表达

值班手册按此动作编排。

G02.03
告警可行动高级开发
核心洞察

没有下一步动作的告警是噪声；告警必须能关联到责任人与 Runbook。

原理映射

饱和、驱逐、拒绝、握手失败等红线独立看板。

工程表达

复盘时清理不可行动告警。

容量与资源预算

G03.01
应用与编排同一容量模型架构级
核心洞察

堆/线程/连接/FD 与容器 limit、探针窗口同一模型，防误杀与假就绪。

原理映射

ActiveProcessorCount、CPU throttle 与 STW 放大一并考虑。

工程表达

容量评审材料含三联对照表。

G03.02
池化与拒绝可观测架构级
核心洞察

有界队列、饱和指标、拒绝告警与降级路径成套；禁止无限队列伪装缓冲。

原理映射

拒绝必须打点并联动降级。

工程表达

池参数变更走审批与回滚。

G03.03
大促前演练清单架构级
核心洞察

分配画像、依赖抖动、单点故障、切流与回滚演练进大促门禁。

原理映射

演练结果进入错误预算讨论。

工程表达

未演练项目不得扩量。

数据变更与 SQL 治理

G04.01
DDL/数据修复可回滚架构级
核心洞察

变更有窗口、备份点、影子验证与回滚剧本；高峰窗口禁止盲上。

原理映射

向前兼容迁移优先于幻想 schema 轻易回滚。

工程表达

大表优先 online DDL 并有中断续跑预案。

G04.02
SQL 审核与慢 SQL 闭环架构级
核心洞察

全表扫/无索引/深分页进 CI；慢 SQL 按总耗时排序并防回归。

原理映射

先 EXPLAIN 再改；计划突变可检测。

工程表达

热点 SQL 与死锁工单闭环到责任人。

G04.03
扩展前先单机架构级
核心洞察

分片前证明单机与索引潜力挖尽；切分键与二次切分成本写 ADR。

原理映射

跨片事务与对账成本明示。

工程表达

未证实瓶颈的分布式方案打回。

缓存一致与热点治理

G05.01
缓存失败可降级架构级
核心洞察

权威在源；缓存挂了不能全站 500，降级路径进 Runbook。

原理映射

策略变更对照命中率与回源，防打爆源库。

工程表达

删缓存失败有补偿与对账。

G05.02
一致性窗口写进契约架构级
核心洞察

旁路/双删/CDC 的最大不一致时间对业务可见可告警。

原理映射

选协议先选容忍窗口。

工程表达

评审材料缺窗口声明则不通过。

G05.03
热 key / 大 key 专项架构级
核心洞察

读热点、写热点、大 value 分型治理并验收。

原理映射

Cluster 槽迁移与热 key 有观测。

工程表达

上线前热点预案（本地缓存/互斥重建）齐备。

调用预算与服务治理

G06.01
同步链路预算入契约架构级
核心洞察

深度、超时、重试上限写进服务契约，端到端可加总。

原理映射

防重试风暴与级联超时。

工程表达

契约变更与代码发布同级管控。

G06.02
治理参数可回滚架构级
核心洞察

限流/熔断/舱壁参数有依据、可审批、可回滚。

原理映射

与错误预算联动。

工程表达

禁止凭感觉调大阈值。

G06.03
双写用 Outbox/CDC架构级
核心洞察

消息与 DB 双写禁止无补偿；Outbox/CDC 兜底。

原理映射

死信可人工补偿且可审计。

工程表达

上线清单含幂等键与对账任务。

AI 制品与评测门禁

G07.01
制品全版本化架构级
核心洞察

模型、Prompt、知识库快照、工具 schema、编排图全部打版本，可回放回退。

原理映射

版本号进日志与审计。

工程表达

事故对齐到制品版本。

G07.02
无黄金集不上线架构级
核心洞察

任何层改动过同一测试集；离线+小流量双确认后再全量。

原理映射

拒绝个例体验放量。

工程表达

评测门禁与发布流水线绑定。

G07.03
工具副作用分级架构级
核心洞察

可写工具默认鉴权、幂等、超时、审计与 HITL；禁止内网裸奔。

原理映射

Token/工具成本进租户配额与门禁。

工程表达

死循环/资损有熔断剧本。

安全运营与供应链

G08.01
威胁建模先行架构级
核心洞察

按资产分级与攻击面建模后再堆控制项；失败时默认拒绝。

原理映射

内网不隐式信任；服务间同样鉴权。

工程表达

高危变更双人+回滚。

G08.02
密钥证书可轮换架构级
核心洞察

到期进日历，轮换可演练，泄露可撤销。

原理映射

密钥不进镜像与仓库。

工程表达

演练「过期当天」应急。

G08.03
依赖与镜像可追溯架构级
核心洞察

SCA 扫描进 CI，维护 SBOM；镜像与基础镜像有升级窗口。

原理映射

对应供应链安全与生产调试端点关闭。

工程表达

例外依赖走审批。
