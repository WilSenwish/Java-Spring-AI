# 全站定位重构规划：从「Java 架构师面试问答」到「Java 专家 / 架构师 / 高级开发 知识库」

> 编制日期：2026-09-03　|　状态：**待决策**（本文档只做规划，不执行任何改动）
> 适用范围：`Java Spring AI` 仓库下的 `java-architect-interview/`（章节站）+ `java-architect-interview-mind/`（导图站）+ 项目根 `index.html`（全量快照）

## 1. 背景与目标

### 1.1 为什么要改

当前全站的品牌词是「**Java 架构师面试问答复习知识点**」，`面试` 二字贯穿 21 个页面标题、1 个内容层名、133 处正文表述。问题有三：

1. **定位窄化**：内容实质是「原理 + 工程实践 + 生产排障 + 架构演进」的完整知识体系，但品牌把它压缩成了「考前复习资料」。
2. **价值感错配**：站内有 `生产量化证据`、`排障 SOP`、`版本演进`、`选型取舍` 等大量生产级内容，被 `面试` 标签掩盖。
3. **对外呈现不友好**：仓库已推 `github.com/WilSenwish/Java-Spring-AI`（`main`，含 `.nojekyll`，按 GitHub Pages 站点在用）。站点标题直接暴露在分享卡片、浏览器标签、搜索引擎摘要上。

### 1.2 目标定位

> **Java 专家 / 架构师 / 高级开发 知识库**

**关键契合点（决定了这次改造成本很低）**：全站现有难度标签体系**恰好就是三级**——
`专家 44` / `架构 160` / `高级开发 141`（合计 345）。新定位的三个层级与既有难度标签**一一对应**，无需新建分类，只需把品牌叙事对齐到已有结构上。

### 1.3 改造原则

| 原则 | 说明 |
|---|---|
| **去面试味，不去内容** | 只改「表述框架」，不动技术事实、不动卡片 ID、不动题目数量 |
| **ID 绝对不动** | `M##.##` / `C##.##` / `E##.##` / `S##.##` 全站锚点与交叉引用依赖，一个字符都不能改 |
| **结构最小化** | `data-layer` 的**英文值**能不动就不动，优先只改中文显示名 |
| **分批可回滚** | 每批次前打 git commit，单批失败不影响其他批次 |
